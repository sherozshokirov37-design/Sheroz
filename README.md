# Минарет: Android-приложение

Игра на одну кнопку: стройте минарет из мозаичных ярусов.

## Вариант 1. Сборка на GitHub (бесплатно, без установки программ)
1. Создайте пустой репозиторий на github.com.
2. Загрузите в него все файлы проекта, включая скрытую папку `.github`.
3. Откройте вкладку **Actions**. Сборка «Build APK» запустится сама и займёт около 3–5 минут.
4. Когда сборка закончится, откройте её и скачайте **Minaret-APK** в разделе Artifacts. Это zip-архив, внутри лежит `app-debug.apk`.
5. Перенесите APK на телефон, откройте его и разрешите установку из неизвестных источников.

## Вариант 2. Android Studio
1. Откройте папку проекта в Android Studio.
2. Выберите **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.

## Где что лежит
- Сама игра: `app/src/main/assets/index.html`
- Обёртка WebView: `app/src/main/java/uz/minaret/game/MainActivity.java`
- Иконки: `app/src/main/res/mipmap-*`

Для публикации в Google Play понадобится подписанный release-билд (.aab) и аккаунт разработчика.
